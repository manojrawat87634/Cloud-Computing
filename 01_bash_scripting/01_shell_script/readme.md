Module 1. (Script Setup & Shell Fundamentals)
(i). Shebang (#!/bin/bash) & File Execution (chmod +x)
(ii). Standard Input, Output & Error Redirection (>, >>, 2>&1)
(iii). Pipes (|) & Command Substitution ($())

Module 2. (Variables, Arguments & Inputs)
(i). User-Defined Variables & Quoting Rules (" " vs ' ')
(ii). System & Environment Variables ($PATH, $HOME, $USER)
(iii). Positional Arguments ($1, $2, $@, $#)
(iv). Interactive User Input (read command)

Module 3. (Control Flow & Logic)
(i). Exit Codes & Success Status ($?)
(ii). Test Expressions ([ ] vs [[ ]]) & Comparison Operators
(iii). File & Directory Testing (-f, -d, -e, -r, -w)
(iv). Conditional Logic (if, elif, else, case)

Module 4. (Loops, Functions & Data Structures)
(i). For Loops (Iterating over lists, files, and command outputs)
(ii). While & Until Loops (Condition-based iteration)
(iii). Reusable Functions, Return Values & Local Variables (local)
(iv). Indexed & Associative Arrays

Module 5. (Text Processing & System Tools)
(i). Searching & Filtering Text (grep, egrep)
(ii). Stream Editing & Pattern Replacement (sed)
(iii). Column Extraction & Report Formatting (awk)
(iv). Finding & Operating on Files (find, xargs)

Module 6. (Advanced Automation & Defensive Scripting)
(i). Error Trapping & Safety Flags (set -e, set -u, set -o pipefail)
(ii). Automated Task Scheduling (cron & crontab)
(iii). Log Parsing, Archiving & Email/Webhook Alerts
(iv). Script Debugging (bash -x, shellcheck)
